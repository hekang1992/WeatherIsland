# WeatherIsland · 气象岛

iOS 17.6+ / SwiftUI / 浅色模式，首页按 iPhone 15 Pro 的 393 × 852 点布局。工程位于桌面 `WeatherIsland`，打开 `WeatherIsland.xcodeproj`，选择 `WeatherIsland` Scheme 即可构建。保留现有签名配置；真机运行需要该设备可用的签名和网络。

App 包含品牌图标、系统启动页与一次性入场动画。正式入口为 `WeatherRootView → WeatherTabsView`，三个 Tab 分别独立维护导航：**天气、我的、设置**。`WeatherHomeView` 为早期离线设计及共享绘制组件，实际多地区首页是 `RegionalWeatherHome`。

## 本轮更新

- 50 幅原创 Canvas 插画统一为 **宋韵画境**，每卷 5 幅：烟岚江渚、庭院清供、水墨行舟、青绿山水、荷风莲影、墨竹松风、远山秋霁、寒江晴雪、花鸟小景、田园清和。采用绢色底、淡墨与青绿、团扇小景、中文竖排题款和朱印，非历史古画复制。
- 设置 → 宋韵画境支持按画卷筛选、查看全部 50 张、试播 11 种天气、应用场景或恢复地区自动匹配。选择保存在本机。
- 全部画面为原创程序插画，无真实城市照片，无图片搜索、下载或远程图片服务。普通地区匹配的是艺术意象，不代表当地实景。
- 首页分为当前天气、未来预报、空气与环境、日照与生活。使用清楚的中文标题、较大字号和深色文字，区分当前值、最近小时预报、全天指标、数据时刻与获取时间。
- 设置画廊和场景预览显式显示系统导航栏与返回入口。
- 定位先使用坐标请求天气，行政区名称异步补齐；名称解析不再阻塞天气。定位名称更新不会清空已加载天气，也不会重复请求同一坐标天气。

## 定位、搜索与城市管理

点击首页定位按钮或「我的位置」时才申请前台权限；不使用后台定位。接受位置后立即展示坐标天气，名称解析最多等待 5 秒。坐标获取最多等待 12 秒；60 秒内的有效系统位置可直接使用。失败保留原地区，并提供搜索或系统设置入口。

精确定位成功时优先展示城市与区县。系统关闭精确位置或精度不足时展示「近似位置」，不展示区县。无法解析行政区时显示「当前位置」，保留坐标天气。区县名代表定位所在行政区，预报仍是该坐标的气象模型数据。

城市搜索使用 MapKit，输入约 350ms 后补全，支持中文、英文城市或区县名称；结果带地址信息以区分同名地区。选中后收藏并返回天气。重复地区打开已有收藏；过期补全与选择请求会取消。

「我的」展示城市天气、当地时间和插画；支持添加、删除、拖动排序、长按设为默认。至少保留一座收藏城市，删除默认或正在查看的收藏时会修复选择。本地恢复上次查看地区、收藏顺序和默认城市；首次使用上海。「我的位置」独立于普通收藏。

## 真实天气与空气质量

无需在工程中填入 API Key。应用配置的服务地址：

```text
天气：https://api.open-meteo.com/v1/forecast
空气：https://air-quality-api.open-meteo.com/v1/air-quality
```

两个请求均按所选地区传入坐标、`timezone=auto`、`timeformat=unixtime`。天气与空气质量独立加载，互不阻塞。日期、小时、日出日落使用天气返回的当地时区；不统一转换成上海时间。

首页内容：

1. 当前气温、体感、今日高低温、天气时刻与动态插画。
2. 今日温差、全天最高降水概率与防晒提醒。
3. Swift Charts 24 时点温度与降水概率，点图表或时段查看对应详情；跨午夜的时段标注明日。
4. 7 天预报与高低温区间。
5. US AQI、PM2.5、PM10，明确使用美国 AQI 标准；未提供的数据不补成 0。
6. 风速风向、湿度、紫外线、能见度、降水量与体感温度。
7. 当地日出日落、日照进度、穿衣、通勤、户外和防晒建议。
8. 独立的天气/空气数据来源、预报时刻和实际获取时间。

当前气温、体感、湿度、风、降水来自 `current`；当前 UV、降水概率与能见度取最近小时预报。每日详情采用全天最大 UV、降水概率、风速和体感，以及日累计降水；接口没有提供的日湿度与能见度显示暂无数据。降水保留 `mm/15分`、`mm/h`、`mm/天` 等正确时间单位。

天气缓存按地区隔离；当前定位按坐标保持稳定身份，补齐地区名称时复用原天气 Store。切换城市取消原页面任务，旧响应不会写入新地区。旧版上海缓存仅迁移到上海。失败时保留同地区缓存并标明日期，不用示例数据冒充实时天气。

天气是模型预报，不是气象站实测或官方预警；穿衣和出行建议由本地规则结合预报生成。

## 晴雨地图

底部新增「地图」Tab，使用可拖动缩放的 Apple 地图，搭配奶油白浮层、墨绿色选点和半透明彩色热力图。

- 右侧切换降水、气温、10 米风速、云量；支持标准 / 卫星底图、回到所选城市。
- 地图内可搜索城市、选择收藏城市，轻点地图读取该位置预报。地图城市独立选择；首页城市变化时地图随之更新。
- 底部展示图例、数值单位和预报时间，支持 12 / 24 / 66 小时范围、逐小时拖动和自动播放。切换 Tab、进入后台时停止播放；减弱动态效果下放慢播放速度。
- 天气使用 Open-Meteo 一次批量请求 7 × 7 个坐标的 67 个小时点，以 Web Mercator 网格双线性插值生成地图热力层。降水为小时累计量，非雷达实测，不提供分钟级雨停判断。
- 拖动地图后点击「查看此区域」请求新区域，避免拖动过程频繁请求。跨日期变更线的坐标会归一化，缺测单元透明，无降水不着色；区域边缘轻柔淡出。
- 同区域数据复用 15 分钟；新区域清除旧图层。加载失败显示重试入口；同区域刷新失败保留原数据与获取时间。离线 Preview 使用明确标注的示例数据，联网失败不替换成示例。
- 选点与移动区域沿用搜索城市的时区；详情面板展示数据来源、网格精度与时间说明。

主要实现为 `WeatherMapView.swift`、`WeatherMapCanvas.swift` 和 `WeatherMapData.swift`。Debug 构建可用 `--map` 直接进入真实地图，`--map-preview` 进入标注示例的离线地图，`--map-layer=temperature` 等参数选择初始图层。

## 动画与 Preview

温度数字使用 `numericText` 和 `easeOut`，无弹跳。插画和天气粒子使用 `TimelineView + Canvas`；后台、隐藏 Tab、详情覆盖与「减弱动态效果」时暂停。宋韵画境中的雨雪、风与雷光调低强度，让特效融入山水；系统「减弱动态效果」时停用动态。

11 种天气包括晴、多云、阴、小雨、中雨、大雨、雷暴、冰雹、雪、雾和大风。天气剧场独立演示特效和示例生活建议，不修改首页真实天气。雷暴使用缓慢局部闪电，不做全屏频闪。

`RegionalWeatherHome`、`SceneGalleryView`、`WeatherSettingsView` 等默认 Preview 使用 `WeatherApplication(live: false)`，不联网、不读取真实缓存。设置中的全局主题、关于、服务协议和隐私政策为「即将开放」，未放置虚构协议。

## 构建与检查

```sh
xcodebuild -project WeatherIsland.xcodeproj -scheme WeatherIsland \
  -sdk iphonesimulator -configuration Debug \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath /tmp/WeatherIsland-DerivedData \
  CODE_SIGNING_ALLOWED=NO build

bash Verification/run-checks.sh
# 可选：额外发起真实天气请求
bash Verification/run-checks.sh --live
# 可选：验证地图的 49 坐标批量接口
bash Verification/run-checks.sh --map-live
# 同套 SwiftUI 绘制代码离屏导出设计预览
bash Branding/export-global-previews.sh
```

`Previews/Art-Directions.png` 是六种宋韵意境放大对照，`50-Paper-Scenes.png` 为全部 50 张，`Global-Weather-Home.png` 为长首页，`Weather-First-Screen.png` 为首页上部，`Weather-Effects-Grid.png` 为天气特效对照。它们是 macOS ImageRenderer 对实际 SwiftUI 组件的离屏渲染，不是 iOS 模拟器截图。

构建和数据回归结果见 `Verification/RESULTS.md`。2026-11-02 已在 iPhone 17 Pro 模拟器验证地图图层、66 小时时间轴、播放与 Tab 切换、选点及真实区域刷新。`Previews/Weather-Map-Precipitation.png` 和 `Weather-Map-Temperature.png` 为标注演示数据的模拟器截图，`Weather-Map-Live.png` 为本次真实接口气温预报截图。真机定位权限、真实搜索输入、小屏与大字号和系统动态效果仍待设备验证。
