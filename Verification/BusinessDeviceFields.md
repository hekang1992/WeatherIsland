# V6.1 原生设备字段逐项对照

对照用户提供的 `iOS H5 登录与设备信息接入规范 V6.1.md`（2026-11-21 核对），共 70 个字段。按用户随后两批明确要求排除 34 项，最终采集代码支持 31 项；另 5 项没有可用于当前上报的可靠值而省略。实际返回数量随窗口、电池和网络等条件变化，不能把支持数量当成本次实际上传数量。

采集逻辑在 `WeatherIsland/BusinessDeviceInfo.swift`。用户排除字段已从采集代码删除，验证程序同时检查原始字段与 Base64 解码结果均不含这 34 项。未知字段直接省略，0/false 保留，不返回 null/空字符串。无额外权限弹窗，无私有 API。

整个 `{"version":1,"fields":{...}}` 先以紧凑 UTF-8 JSON 序列化，再整体 Base64 一次。桥回调直接返回字符串；HTTP 的 `nativeDeviceInfo` 对应同一字符串，保持用户补充要求优先于文档中的对象示例。限制为 8192 原始字节、96 项字段、字符串 128 Unicode 标量且无控制字符。

## 平台核对依据

- Apple 官方 Required Reason API 原因列表：<https://developer.apple.com/documentation/bundleresources/app-privacy-configuration/nsprivacyaccessedapitypes/nsprivacyaccessedapitypereasons>。磁盘空间的显示、写入空间判断用途不允许通过互联网传出；可选错误报告/健康研究用途不适用当前设备风控接口，所以不添加存储容量字段。
- `NetworkExtension/NEHotspotNetwork.h` 要求 Wi-Fi Info entitlement 和符合系统条件的现有授权；缺少时返回 nil。当前不改变签名 capability 或请求新定位权限，拿不到就省略。
- 用户排除的 SIM、传感器能力、调试、定位来源与 UUID 等字段及相关专用读取逻辑已删除。当前网络类型仍按可确定的蜂窝制式提供。

## 验证范围

`BusinessDeviceFieldSchema.json` 按这份文档的 70 行字段表生成，供 `BusinessDeviceInfoChecks.swift` 独立模拟器检查 App 使用。检查 App 不调用 Adjust 或业务后端，不保存任何设备字段原值，仅输出字段名、数量和通过结果。验证内容包括字段白名单、JSON 类型/范围、兼容键配对、未知省略、无窗口省略、34 项用户排除字段在采集及编码后均不存在、完整 Base64 对象与大小限制。

实际真机电量、Wi-Fi 授权数据和真实后端保存结果仍需在对应设备与环境验证。H5 本地等待异步原生回包的修复尚未部署到测试站；原生补齐不能替代 H5 部署，也不能直接证明后端已经存储这些字段。

## 最终删减后的验证结果（2026-11-21）

- CocoaPods 工作区 `WeatherIsland.xcworkspace`，Debug / iOS Simulator 完整构建成功。
- 独立 iPhone 18 Pro / iOS 27.0 模拟器检查实际得到 23 个字段；代码共支持 31 个字段，未以占位值凑齐数量。
- 34 个用户明确排除的字段在采集字典与完整 Base64 解码结果中均不存在。
- 字段白名单、类型与范围、首选/兼容键一致、未知值省略、无窗口省略和 Base64 对象/大小约束全部通过。
- 原有桥接 Swift 检查通过；相关 H5 设备、iOS 桥接与登录恢复测试共 24 项通过。
- 此结果来自原生采集与桥接验证，没有进行新的账号登录或后端上报；测试站 H5 的异步等待修复仍待部署。
